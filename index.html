Research Assistant, Gravity Spy 2.0

Syracuse iSchool
Feb. 2026 to Present · PI: Prof. Kevin Crowston · NSF funded
  • Classifications276,000+ parsed
  • Subjects25,104 glitch subjects
  • Channels Mapped8,293 auxiliary
  • Model0.89 val AUC · ECE 0.10 to 0.05

Research assistant on an NSF funded citizen science project supporting LIGO (the Laser Interferometer Gravitational Wave Observatory). The scientific goal is causal inference on detector noise: figuring out which auxiliary subsystems are responsible for the transient glitches that contaminate gravitational wave strain data, so detector commissioners can fix the right hardware rather than chasing symptoms.

Built the end to end data ingestion pipeline in Python using Pandas and the Zooniverse Panoptes API, parsing 276,000+ volunteer classifications across 23 months of LIGO observations. The engineering work was reconciling five undocumented subject metadata schemas across project iterations, spanning 25,104 glitch subjects and 8,293 auxiliary detector channels, filtering out roughly 38 science team and developer accounts, and resolving field naming differences between schemas (for example, #gps versus #gps_time).

Engineered an OpenCV image processing workflow that retrieved 49,000 spectrograms through batch API calls, transforming 1200x1200 mosaic images into paired 224x224 channel heatmaps suitable for deep learning input.

The pipeline produces three core outputs: a subject level flat file with aggregated volunteer labels (Yes, No, Not Sure counts, total classifications, majority vote), a separate file for subjects missing GPS metadata, and a GPS time by auxiliary channel pivot matrix covering 455 LIGO subsystems including PEM, SUS, LSC, ISI, ASC, and CAL.

Trained a two-input Convolutional Neural Network with a shared MobileNetV2 backbone in TensorFlow and Keras to predict volunteer similarity labels directly from paired spectrograms, reaching a validation AUC of 0.89 on a held out 2,000 subject set. The result I care about more is calibration: applying label smoothing, the AdamW optimizer, and AUC based early stopping brought Expected Calibration Error down from 0.10 to 0.05, which matters because downstream researchers consume the model's confidence scores rather than only its rankings. The trained model produces a glitch type by auxiliary channel similarity matrix that maps detector subsystems to specific glitch morphologies.

Alongside the modeling, conducted the full descriptive analysis: volunteer effort distribution (heavily right tailed, with the top ten volunteers accounting for 50% of classifications), subject level inter volunteer agreement (52% perfect consensus on multi classified subjects), and response distribution across workflow versions. Code is committed to the Syracuse CCDS GravitySpy Classifier repository.
